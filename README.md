# oddlyspaced/tap

Homebrew tap for personal casks.

## Install

```sh
brew install --cask oddlyspaced/tap/crumb
```

Or tap first:

```sh
brew tap oddlyspaced/tap
brew install --cask crumb
```

## Casks

| Cask | App | Homepage |
| --- | --- | --- |
| `crumb` | Crumb, a command bar agent for ordering on Swish (Apple Silicon, macOS 13+) | https://crumb.justswish.in/ |
